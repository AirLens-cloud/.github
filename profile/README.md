# AirLens

Free, no-account global air-quality observation — **[airlens.cloud](https://airlens.cloud)**

AirLens combines ground stations, satellite aerosol data and forecasts into one public view of the air you breathe, and explains it in plain language.

| Area | What it does |
|---|---|
| Real-time observation | Collects station and low-cost sensor data (OpenAQ, Sensor.Community, national networks) every hour |
| Satellite & prediction | Corrects satellite aerosol optical depth into surface PM2.5 estimates and short-range forecasts |
| Policy interpretation | Estimates how air-quality policies changed outcomes, country by country |
| Interpretation assistant | Answers questions about the current data with cited sources |

## Open data
Published hourly as a public Hugging Face dataset: [`Robeedau/airlens-live`](https://huggingface.co/datasets/Robeedau/airlens-live).
